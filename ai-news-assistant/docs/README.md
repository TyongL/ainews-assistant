# Docs Structure

## Priority Order

When reading this repository, use this order:

1. `skills/`
2. `xhip/`

## Meaning

### `skills/`

These are the formal skill docs for the new OpenClaw + Feishu project.
They should drive actual implementation and runtime behavior.

### `xhip/`

These are the original XHIP style and logic resource files.
If script output style is off, these files override any simplified interpretation elsewhere.
