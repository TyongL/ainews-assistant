# 晓辉博士口播稿生成

## 核心目标

将用户当前的笔记或资讯讨论成果，转成：

- 晓辉博士风格的短视频口播稿
- 带传播性的分享标题与导语
- 可直接发布或二次编辑的成稿

## 风格基线

你必须把以下原始资源作为正式基线：

- `docs/xhip/tone_and_persona.md`
- `docs/xhip/logic_and_style.md`

如果生成结果和这两个文件冲突，以这两个原始资源为准。

## 输入来源

优先级如下：

1. 飞书笔记文档
2. 已整理好的认知笔记内容
3. 用户直接粘贴的文章或文本
4. URL 原文

## 工作流

### 步骤 1：识别输入材料

判断当前是：

- 笔记
- 原文
- URL
- 直接文本

并自动抽取主题。

### 步骤 2：加载风格与逻辑资源

必须显式加载：

- `tone_and_persona.md`
- `logic_and_style.md`

并优先通过以下脚本完成知识库召回与 prompt 组装：

- `scripts/generate_xiaohui_script.py`

该脚本负责：

- 调用知识库召回
- 加载风格资源
- 读取用户原文或笔记
- 生成完整 prompt
- 写出 `outputs/temp_prompt_for_agent.txt`

### 步骤 3：生成传播文案

至少生成：

- 分享标题
- 引言摘要
- 口播稿正文
- 稿件结构概览

### 步骤 4：生成口播稿正文

必须遵循晓辉博士核心特征：

- 开场有活人感
- 有情绪
- 有类比
- 有 Hook → Deep Dive → Impact 的结构
- 结尾自然收束

### 步骤 5：写入飞书并回写状态

- 创建飞书口播稿文档
- 回写 `口播稿` 链接到 Bitable
- 更新状态为 `scripted`

## 执行主链

默认顺序必须是：

1. 运行 `scripts/generate_xiaohui_script.py`
2. 读取脚本输出的知识库上下文与 prompt 文件
3. 基于该 prompt 生成正式口播稿
4. 写飞书文档
5. 回写状态

## 强制规则

1. **必须参考原始风格资源**
2. **输出必须是成稿，不是摘要**
3. **必须显式生成分享标题与引言摘要**
4. **风格不对时，先修正风格，不要只补信息**
5. **生成完成后必须回写飞书状态**
6. **不要绕过知识库脚本直接硬写口播稿**
